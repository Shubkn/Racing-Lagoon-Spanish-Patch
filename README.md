**Traducción al español latino para el juego Racing Lagoon**

La traducción abarca el juego al completo utilizando de base el parche de traducción inglesa, por lo cual los textos de interfaces graficas estarán al ingles, pero fuera de eso todo lo demás esta al español de latam(la traducción no contiene modismos)

Para transparentar y dejarlo en claro del principio, me ayude con IA para realizar el trabajo, obviamente se realizaron revisiones y testeos para ir solucionando errores entre otras cosas

Este es el primer entregable, por lo cual quiero realizar otra revisión para pulirlo aun más, el parche como tal ya esta traducido y se puede terminar el juego sin problemas, pero hay algunos dialogos (muy pocos tirando al final) que se salen un poco del encuadre, cosa que quiero corregir

El parche se aplica sobre el ID japones SCPS-45404
